# Asymmetric algorithmic organization of relational memory

## Status

This document freezes the current model-side computational theory. It is an
evidence synthesis only: no checkpoint was replayed, no model was trained, no
human data were reanalyzed, and no new scientific estimand or threshold was
introduced. Exact source hashes and claim boundaries are recorded in
`benchmarks/asymmetric_algorithmic_organization_v1.json`.

The central conclusion is:

\[
\boxed{
\text{local computation is algorithmically compressible, while global}
\atop
\text{representation is geometrically compressible but its tested learning states are not closed.}
}
\]

This is an asymmetry between representation and computation, not a proof that
the global computation has irreducibly high intrinsic dimension.

## Three evidence levels

### 1. Phenomenology

The frozen nine-row map classifies six Liu phenomena as reproduced, three as
qualitatively reproduced but quantitatively mismatched, and none as absent.
The reproduced set includes learned and nonlearned accuracy, pairwise
polarization, stable individual errors, coherent subjective rankings, and
inter-subject ranking diversity.

The three constraints remain part of the theory:

1. symbolic-distance dependence is too steep;
2. the serial-position endpoint contrast is too weak; and
3. seed 2104 overproduces self-inconsistent subjects while seed 2105 does not.

These are competence-qualified model discrepancies, not targets to erase by
temperature or checkpoint selection. Model reproduction is not evidence that
the same internal computation is used by humans.

### 2. Functional decomposition

The replicated and fresh-backbone interventions support:

```text
observed support evidence
  +-- selective effective admission --> P_T --> remote/global relational assembly
  +-- broader weak local admission ---> a_T --> query-addressed direct fidelity
```

Here `a_T` is the algorithmic coordinate system exactly equivalent to the
frozen tensor local state `L_T`. Under `P`-off, direct learned fidelity remains
while nonlearned inference and remote effects collapse. Under local-off, the
model exactly restores v1 while the global competence and mechanism gates
remain intact. Matched evidence routing and matched query addressing beat
their frozen derangements.

This establishes a functional division of labor. It does not establish two
biological stores, unique tensor-product coding, network-population
prevalence, or a unique human evidence-admission rule.

### 3. Algorithmic asymmetry

The local implementation compresses exactly:

\[
a_{t+1}=a_t+s_t^L e_{r_t},
\qquad
\ell_q=(K a_T)_q,
\qquad
K_{qr}=k_q^\mathsf{T}k_r.
\]

The reconstruction discrepancy is approximately `1e-14`. For algorithmic
exposition, `a_t` should therefore be preferred to the original tensor
coordinate `L_t`, while the latter remains the actual implementation from
which the equivalence was derived.

The global terminal field is also simple at the representational level:

\[
m^G_{ij}(P_T)\simeq s_i-s_j,
\]

with terminal Hodge fractions above `0.996` in the registered generic audit.
But this potential does not close the learning dynamics. The tested sequence
of increasingly permissive hypotheses gives a consistent boundary:

```text
s_t alone
  -> rank-2 and full bilinear transitions fail
scalar history
  -> restores remote amount but misallocates the field
item history
  -> improves allocation error but loses remote amount
full residual functional-P linear readout
  -> fails held-out prediction and reverses remote allocation
```

The final full-`P` audit is not merely a failed low-rank approximation: rank 7
reconstructs its full oracle, while rank 1 is already harmful. The correct
conclusion is therefore:

\[
\boxed{
\text{simple low-dimensional output geometry}
\not\Rightarrow
\text{stable low-dimensional learning coordinates}.
}
\]

## Frozen computational theory

The current model is best written asymmetrically:

\[
\text{support evidence}
\longrightarrow
\begin{cases}
P_t & \text{distributed, history-dependent plastic computation},\\
a_t & \text{additive edge-addressed persistent memory},
\end{cases}
\]

followed by

\[
m_{ij}
=
m^G_{ij}(P_T)
+
\lambda_L(Ka_T)_{ij}.
\]

The two branches have different computational roles:

| Global branch | Local branch |
|---|---|
| interacting fast-weight state | explicit edge state |
| history-dependent gain and allocation | additive accumulation |
| remote relational consequences | direct/query-addressed fidelity |
| terminal output approximately potential-like | output relation-specific |
| not closed by the tested compressed variables | exactly compressible |
| abstraction and global coherence | preservation of direct experience |

The global implementation is high-dimensional in the current network, and
`P`-off interventions establish its causal necessity. The evidence does not
show that the global algorithm is intrinsically high-dimensional, nor that no
nonlinear, trajectory-dependent, or episode-specific compact state can exist.
Those possibilities are logically open. The accumulated negative evidence
means there is no current scientific reason to continue searching for such a
state by changing compression tools.

## How the negative results contribute

The reduced-algorithm sequence is a positive argument about global-state
complexity, not a collection of discarded models.

- v1 separates near-additive output geometry from dynamical closure.
- v2 shows that accumulated history controls global update amount.
- v3 shows that relational allocation cannot be reduced to the same scalar
  history and that item allocation alone loses the correct amount.
- The functional-`P` audit shows that gain and allocation do not become a
  transferable fixed linear coordinate merely by exposing the complete
  residual fast-weight matrix.

Together they support distributed, state-dependent interaction as the current
mechanistic description of global reassembly. They do not license the stronger
claims “no low-dimensional state exists” or “intrinsic dimension is high.”

## Closed routes

Stop the reduced-global-algorithm search. Do not respond to the current result
by changing bilinear rank, combining scalar and item ledgers, adding pair/time/
count features, tuning ridge, normalizing `P_t`, applying PCA, or introducing a
nonlinear kernel. Do not begin autonomous latent closure because no sufficient
latent readout was established.

Preserve the exact local algorithm, all global causal mechanisms, the v2/v3
amount-versus-allocation fingerprints, and the fixed-linear-readout negative.
The project-level question remains how sparse and partially encoded evidence
produces a stable and individualized relational structure; only the attempted
route to a symmetric low-dimensional algorithm is closed.

## Next model-side program

Generalization should now ask whether the **functional asymmetry** transports,
not whether one reduced coordinate transports. The first prospective priority
is a one-to-three-seed list-linking pilot:

```text
two learned sequences + one bridge relation
  P_T prediction: remote restructuring across the two lists
  a_T prediction: bridge/direct fidelity without transitive reconstruction
```

The pilot must freeze task generation, competence, `P`-off/local-off
interventions, direct-versus-remote estimands, and stop rules before execution.
Only after that decisive bridge regime should the program expand to item count,
support topology, evidence sparsity, and adjacent-pair transitive inference.

A later Miconi ancestry analysis should compare causal computational motifs:
whether new evidence acts on a distributed plastic state carrying accumulated
relational context and thereby restructures remote relations. It should not
attempt to align individual latent coordinates or claim common biological
implementation from a functional analogy.

Human experimental design remains deferred. No new human result is required
to state or test the present model-side theory.

## Frozen claim boundary

The strongest supported statement is:

> In the frozen FSRL model family, selectively admitted evidence drives an
> interacting fast-weight computation whose terminal output is nearly
> potential-like and globally coherent, while a broader, query-addressed local
> trace is exactly reducible to an edge-state algorithm that preserves direct
> relational fidelity.

Do not replace it with any of the following:

- the human brain uses the same two states;
- `P_T` and `a_T` are anatomically separate memory systems;
- the global computation is intrinsically high-dimensional;
- no compact nonlinear sufficient state exists;
- the edge kernel, tensor key, local admission probability, or recurrent
  implementation is unique; or
- all human behavior has been reproduced.
