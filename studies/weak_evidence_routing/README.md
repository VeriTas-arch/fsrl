## Scientific role

**Question.** Does selectively withholding weak global evidence restore coherent
individual variation while local evidence remains available?

**Finding.** All three paired seeds support the registered routing effect and isolated
core behavior; all isolated N=8 models pass nine qualitative rows. Triggered N=6/10
evaluation completed for every model, with all nine isolated size cells passing core
checks. Accuracy decreases materially; shared also has core-qualified networks, so
isolation is not established as necessary. Frozen development evidence, without
main-model promotion.

**Claim boundary.** Three paired developmental seeds, fixed joint recipe and simulated
cohorts; routing plus adaptation, without human confirmation, learned-gate claims or
automatic promotion.
