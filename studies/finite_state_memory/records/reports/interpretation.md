# 有限状态快速记忆：结果与结构决定

本研究获得资源节约和训练适应的正结果，但没有支持预注册的行为形成机制。四条件在三条配对训练流中均保持通用能力与四项核心行为组织；十二个训练模型全部未通过个体差异判据，新增历史功能选择及形成互补判据也未通过。登记为 **mixed**，关闭本轮 K=65、随机存储与固定写入成本配方；不作主模型晋升。

## 实验身份与边界

科学依据是[冻结协议](../benchmarks/protocol.json)、[开发选择锁](../benchmarks/selection_lock.json)、[完整模型锁](../benchmarks/model_lock.json)及[规范结果](../results/result.json)。协议 SHA256 为 `7199a7c2ca0282d78ca92c15000576b617f75560a6e5ff835b1308210e551475`；实现与资格见证提交为 `f063458e02b18a5fc5150c7a8f7bc0a06eea715d`，源与输入锁提交 `8ee946f`，开发模型锁 `e40809e`，选择锁 `7404388`，十二模型评价前锁 `03f53a8`。结果提交是首次提交本报告及规范结果的 Git 提交，可由文件历史定位。

开发种子 2331 训练 Shared 与 K=65、257、1025 共四个模型；全部模型先锁定，再仅凭独立通用任务能力及配对 CE 损失上界选择最小合格 K。三个 K 均合格，因此固定 K=65。正式种子 2332、2333、2334 各从头单阶段训练 Shared、Cost、Precision、Cost＋Precision，共十二个模型。每个模型 1500 步、每步 32 episodes，同一配对种子共享初始化与任务流。成本系数固定为 100.23260880257861，没有再次搜索。

最终协议检验的是**每条快速连接的可用状态数 K**：实际 P 在 [-50,50] 的 K 个等距状态上随机舍入，无连续影子或余数缓存。α 可训练且在 episode 内固定，有效连接 A=α⊙P，因此有效间隔是 |α|×100/(K−1)，并非所有连接共享同一个固定有效分辨率。α 缩放是协议允许的适应，不能宣称已证明全系统容量受限，也不能把这次负结果外推到所有固定有效分辨率模型。局部 L 保持连续；这是只限制全局存储的不对称假设。

外环使用状态直通梯度。成本前向取实际接受的有效连接 L1 修改量；有限状态成本反向使用一步条件期望的梯度。后者与循环状态的直通梯度都属于公开的优化近似，不是精确随机循环损失梯度或生物局部学习证据。

评价包含 256 个通用任务 episodes、128 个配对历史 episodes、固定的新 77 人模拟面板。六个评价条件还包括将 K=65 急性施加到新训练连续 Shared/Cost 的两个对照。每个模型作三次固定输入的编码重放；仅 replay 0 承担主行为评价。网络、被试与重放不混池；区间为各网络内部 2000 次配对 bootstrap，不能据此估计网络总体通过率。这是已知 Liu 现象下的发展实验，不是盲确认。

## 能力与核心行为

下表依次报告三个种子，CE 为通用任务完整输出；条件 τ 是完整输出中满足历史分析条件的模拟被试排序相关，all77 τ 是固定全部被试的全局期望排序相关，二者不是同一估计量。

| 条件 | 通用 CE：2332 / 2333 / 2334 | 完整输出条件 τ | 全局 all77 τ | 完整核心通过 |
| --- | --- | --- | --- | --- |
| Shared | 0.1121 / 0.0863 / 0.1226 | 0.855 / 0.848 / 0.859 | 0.934 / 0.954 / 0.938 | 0/3 |
| Cost | 0.1651 / 0.1688 / 0.1667 | 0.838 / 0.860 / 0.870 | 0.918 / 0.936 / 0.930 | 0/3 |
| Precision | 0.1477 / 0.1136 / 0.1476 | 0.825 / 0.838 / 0.866 | 0.901 / 0.932 / 0.930 | 0/3 |
| Cost＋Precision | 0.1707 / 0.1740 / 0.1738 | 0.833 / 0.852 / 0.849 | 0.918 / 0.913 / 0.915 | 0/3 |

全部十八个评价条件在完整输出和全局输出上均通过能力、连贯性、稳定错误和有组织错误检查，唯一失败项均为个体差异。冻结标准要求条件 τ 的 95% 区间上界低于 0.8；本轮连点估计都高于 0.8，并非仅因区间过宽。该判据不要求与人类分布完全吻合，也不要求历史九行统计全部通过。

每个训练模型的完整输出 eligible 均为 77；剔除正确排序者后的分析人数依种子为 Shared 34/25/36、Cost 37/31/39、Precision 43/32/39、Cost＋Precision 39/38/41。条件 τ 的组间差异采用原始 77 个 ID 配对重采样后再应用各自分析掩码；all77 指标用于避免把不同条件的筛选组误当作固定队列。完整输出与全局输出结论一致。

## 正结果：成本与适应

Cost 在三个种子中均大幅降低实际有效写入量；Cost＋Precision 也明显低于对应无成本 Precision。Cost＋Precision 的平均实际写入成本略高于 Cost，故不能把联合条件描述为所有资源指标都更优。

相对于急性舍入 Cost，Cost＋Precision 的通用 CE 在三个种子中均改善，配对区间全为负。训练也使全局 all77 τ 分别增加约 0.051、0.049、0.044：适应恢复了更相似的关系结构，而不是所需个体化。Precision 相对急性 Shared 的 CE 改善仅一个种子区间明确为负，不能将适应收益泛化为四条件普遍结论。

| 配对 CE 对比，单位 nats | 2332，95% CI | 2333，95% CI | 2334，95% CI |
| --- | --- | --- | --- |
| Cost＋Precision − 急性 Cost | -0.03313 [-0.03852, -0.02739] | -0.03561 [-0.04177, -0.03002] | -0.03427 [-0.04060, -0.02847] |
| (Cost＋Precision − Cost) − (Precision − Shared) | -0.02996 [-0.03661, -0.02334] | -0.02200 [-0.02789, -0.01656] | -0.01786 [-0.02461, -0.01097] |

负的 CE 交互表示：有限状态在成本背景下带来的额外任务损失较小。它是任务性能层面的资源交互，不是预注册的历史功能选择或行为形成互补；联合条件的绝对 CE 仍高于 Shared 和 Precision。

固定输入编码重放的全局 margin 方差，Cost＋Precision 为 0.154/0.158/0.171，急性 Cost 为 0.690/0.731/0.843；连续条件为零。这说明联合训练后的输出波动描述性地更小，但 margin 单位受读出增益影响，三次重放也只用于诊断，不能直接解释成人类记忆稳定性或有效存储 bit 数。

联合条件在 Liu 终态平均使用约 18–19 个可用 P 状态，Precision 约 59–65 个；α 与有效间隔也发生变化。补偿性重参数化是候选解释，尚未由这些状态统计单独确定因果中介。

## 负结果：没有新增功能选择

主功能终点为全局原生 CE 的目标证据贡献：B = CE(撤去目标) − CE(完整)。历史面板比较当前观察相同但先前目标信息新颖或冗余的情况，再比较模型间的“新颖 − 冗余”差异。这里仅撤去指定目标出现，以保留历史差异；另一个 Liu 关系贡献面板才联合撤去该关系全部重复。局部证据始终保留。

协议诊断 metrics 字段保留了来源研究的写入份额描述；本研究 question 与 decision 字段明确规定以全局 CE 历史交互作主功能判断，写入份额和远端变化为支持性结果。本报告依该冻结 decision 解释，不因其他指标有利而替换终点。

| 历史全局 CE 贡献对比 | 2332，95% CI | 2333，95% CI | 2334，95% CI |
| --- | --- | --- | --- |
| Cost＋Precision − Cost | +0.00256 [-0.00007, +0.00522] | +0.00177 [-0.00131, +0.00477] | -0.00128 [-0.00458, +0.00173] |
| 成本 × 有限状态交互 | -0.00028 [-0.00694, +0.00582] | +0.00407 [-0.00285, +0.01098] | +0.00509 [-0.00172, +0.01159] |

上述区间全部跨零。Precision − Shared 同样没有跨三个种子的正证据，第三种子反而为负。所有种子的新增功能选择判据及形成互补判据均未通过。Cost 和联合条件自身的新颖性效应仍存在，故正确结论是“新约束未带来受支持的新增功能选择”，而不是“网络没有历史依赖”。跨零也不构成效应严格为零的证明。

## 结构决定及下一问题

保留两个结果：网络确实能节约连接修改；网络也确实能适应实际离散存储。删除当前理论中的未获支持因果推断，即“这两种约束结合就会使网络形成连贯而不同的关系结构”。isolated RNN 继续作为已有行为工作模型，这轮不晋升新候选。

停止本轮具体配方，不扩 K、成本或随机性网格，不为通过 τ 而追加门控、遗忘或低秩结构。下一项研究若开启，应先在两个清楚的问题之间选择：保留 isolated 的选择性接入作为有效结构假设；或提出有独立任务依据的观察不确定性生成假说。当前弱通道仍提供方向正确的证据，低幅度不等于观察方向不可靠；这可能比继续叠加存储约束更值得辨识，但本轮结果没有证明哪一替代机制正确。本记录不授权后续训练或新估计量。

## 验证与归档

[资格记录](../benchmarks/qualification.json)含 116 项 CUDA 检查；[补充编译梯度核对](../artifacts/validation/compiled_gradients.json)含 52 项比较，最大绝对误差约 7.45×10⁻⁹，未使用拟合模型或 Liu 数据选择实现。源码修改在训练前完成，此后未改冻结实现。工程套件通过 739 tests 与 318 subtests；Ruff、格式、类型和结构检查通过。

原始数组独立重建通过 84 项均值对比及区间、84 项 τ 对比及区间、36 项路线判定和 36 个编码重放数组；通用 CE 与历史 CE 贡献也从 margin 和目标重建。规范结果归档 284 个成员，与运行产物逐字节一致，含 74 份有效且完成的运行 manifest、16 套骨干及局部模型、输入、训练日志与评价数组。最大单文件约 1.88 MB，低于仓库单文件存储审查阈值。结构验证与这些复核不提高科学证据等级。
