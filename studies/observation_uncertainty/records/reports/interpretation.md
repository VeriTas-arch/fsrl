# 观察不确定性：行为分化与训练适应

本轮为 **mixed**。观察误差急性作用于原输入训练的 RNN 后，三个种子的完整输出与全局输出都通过本轮核心行为判据，并保留能力和证据绑定。从头适应同一误差的 C 提高了预测能力，却只在一个种子的完整输出通过核心判据，全局输出均未通过；注册的新增历史功能判据在三个种子中均失败，且区间均位于预期方向的反面。

这支持“观察不确定性能够在现有 RNN 上产生有组织的个体化行为”和“网络能够学习适应这种不确定性”，尚不支持“适应训练稳健形成了目标个体化及新增历史选择”。保留急性条件的正结果，不把它仅因缺少误差训练便归为无组织损伤；也不把其成功升级为形成机制或主模型晋升。

## 依据、设计与信息边界

权威依据为[冻结协议](../benchmarks/protocol.json)、[源码与输入锁](../benchmarks/source_lock.json)、[开发模型锁](../benchmarks/development_model_lock.json)、[能力筛选锁](../benchmarks/screen_lock.json)、[全部主模型锁](../benchmarks/model_lock.json)及[规范结果](../results/result.json)。补充历史 CE 位于[独立采集结果](../artifacts/secondary_history_replay/result.json)。

开发种子 2431 的 A/B/C 全部完成并锁定后才查看通用能力；三者均通过完整／全局能力要求。随后使用 2432、2433、2434 的三个配对初始化，九个模型全部训练和锁定后才评价。每个模型单阶段联合优化 1500 步、每步 32 个 episode；架构维持 H=200、连续快速连接与原局部路径，不加有限状态或写入成本。每个网络独立分析 77 个模拟被试，通用任务 256 个 episode，受控历史 128 对；三个编码重放中只有 replay0 进入主判定。下文按 2432／2433／2434 排列，区间为网络内配对的 2000 次描述性 bootstrap 95% 区间，不将被试跨网络合并。

观察公式为 u=d[z+(1-z)p]、v=u+σε。A 使用原数组；B 使用 sign(d)|v|；C 使用 v。σ=1/7 是一个显示等级差单位的计算假设，未由 Liu 行为拟合。B/C 共用逐次呈现的独立高斯误差和绝对幅度；两条记忆路径共用 q，循环通道为 (zq,q)，不另给局部路径干净证据。B 是真方向恢复的 oracle 对照，不是拟议的人类机制。p/z 接入脚手架仍然存在，不能把结果解释为已说明其来源或必要性。

固定的非 Liu 预检中，单次呈现方向错误为 472/9088（5.194%），同一关系四次平均后为 31/2272（1.364%）。此面板只说明该固定算子的输入后果，未用来选择尺度，也不是人类错误率估计。

## 训练改善任务预测，并部分恢复同质性

C−急性在完全相同的带误差评价输入上比较训练适应：

| 种子 | 通用 CE 差及 95% 区间 | 全体全局 τ 差及 95% 区间 |
| --- | --- | --- |
| 2432 | -0.02626 [-0.03545, -0.01817] | +0.04599 [+0.02211, +0.06982] |
| 2433 | -0.03306 [-0.04376, -0.02269] | +0.05283 [+0.02664, +0.07896] |
| 2434 | -0.02481 [-0.03371, -0.01620] | +0.04780 [+0.02114, +0.07314] |

三组均降低 CE、提高排序相似度，支持训练适应，同时说明这种适应削弱了急性条件的分化。但 C 的全体全局 τ 约 0.83，仍低于 A 的约 0.92；应称部分恢复同质性，不能写成完全消除了观察误差效应。

三次重放的全局 margin 方差分别为：B 0.890/1.089/0.867，C 0.926/1.108/0.898，急性 2.806/4.192/2.618，A 为零。这与 C 的较稳健输出相容，但重复次数少、margin 增益可变，不能由此估计记忆容量、噪声减少比例或跨独立学习会话的个人特质稳定性。

## 方向误差的额外作用尚未跨三组成立

B 已使全体全局 τ 从 A 的约 0.92 降至 0.84–0.85，因此幅度扰动本身具有实质连续效应。C 相对 B 的预测 CE 在三组均增加；进一步降低全体全局 τ 的方向一致，但只有 2432 的区间不跨零。

## 历史功能：预测更准不等于注册交互增加

所有网络和最小二乘对照读取同一组已编码的支持／冲突历史。当前目标观察与局部输入相同，冲突历史通过交换目标两项在前缀中的身份和查询真值构造。这是受控一致性挑战，不是 Liu 自然学习分布。A 与急性是同一模型读取相同面板，故其历史结果相同。

定义 B=CE_global(撤去末次目标的全局写入)−CE_global(完整)。注册机制主量是 C−A 的“支持历史 B−冲突历史 B”，要求区间下界为正。

| 种子 | 注册历史主量及 95% 区间 |
| --- | --- |
| 2432 | -0.03506 [-0.04273, -0.02839] |
| 2433 | -0.04209 [-0.05247, -0.03190] |
| 2434 | -0.02891 [-0.03576, -0.02289] |

三组区间均低于零，支持的是注册交互向反方向变化，不能描述成仅缺统计效力，也不能改判为新增历史选择。B−A 也均为负，C−B 仍为较小的负区间。这不等于网络没有历史依赖；远端输出受目标写入影响等已有量仍保留。CE 交互还可受输出增益、目标真值和原有误差结构影响，不足以定位门控或证明网络抑制了错误写入。

## 简单积分对照与机制边界

最小二乘对照对普通项目身份和 q 拟合居中的项目分数，使用固定 1/σ 读出，无另行训练或人类校准。它未使用真值/p/z，但也没有充分利用循环双通道可透露的 z 信息，因此是共享观察的简单积分对照，不能称为全部输入信息下的贝叶斯最优算法。

其 clean/folded/noisy 通用 CE 为 0.14756/0.16271/0.16600，全体排序 τ 为 0.86222/0.83224/0.82341；三个条件均因多样性门未通过完整核心。noisy 的条件 τ=0.77220，区间 [0.74632, 0.80646]，与 C 的连续行为水平接近。不能仅凭一个 RNN 区间上界跨过 0.8、对照未跨过，就宣称 RNN 独有机制已被识别。

三种观察条件的对照共用同一受控历史，完整与全局输出按定义相同；历史支持／冲突 CE 为 0.17399/0.17775，B 的支持−冲突差为 0.00376，区间 [-0.00225, 0.00955]。它没有额外局部路径，query-shuffle/P-off 的对应退化意义不能视为三次独立机制重复。

## 理论修正与下一问题

1. 保留 isolated RNN 作为既有行为工作模型，保留成本／有限存储适应结果；本轮增加“急性观察不确定性＋已训练 RNN”这一通过能力和核心组织检查的功能参照。两者均不自动晋升为已解释形成来源的最终主模型。
2. 不再把“误差使个体不同”与“训练会维持这种不同”混为一谈。本轮同时支持前者及预测适应，并显示后者只部分成立。也不能仅凭这种分化反推人类感觉误差来源。
3. 下一项最小诊断是补成“原输入／误差输入训练 × 原输入／误差输入评价”的 2×2。本轮已有 A→原输入、A→误差输入、C→误差输入，尚缺 C→原输入；可先用冻结权重、同一批物理输入补这一格，不需新增训练。另行预注册四格的全体全局 τ 与 CE 交互，判断训练是否减少了观察误差带来的分化，还是在两种输入下都改变了关系计算。核心五项仍联合报告。该比较只能定位训练策略与观察敏感性的关系，不能直接定位内部回路或证明人类采用训练／评价分布不匹配。
4. 这项交叉诊断属于新的评价与估计目标，须在独立协议中执行，不能回写本轮判据。随后若优先验证功能候选，冻结急性流程做独立种子／队列重复；若继续解释形成，则依据交叉结果选择一个最小训练条件对照，并把预测适应与个体化的共同保留作为联合终点。不要先选能通过的中间训练检查点再称为形成证据。
5. 本轮停止于这一固定 σ 配方的 mixed 结论，不追加噪声网格、相关个体偏差、门控、容量限制或新行为阈值。没有新增人类数据分析、跨项目数迁移或主模型晋升。
